# Как запустить программу?
- Запустить исполняемый файл "*Mega PhotoEditor.exe*", находящийся в папке *app*;
- Создать проект и загрузить библиотеки из файла `requirements.txt` с помощью команды `pip install -r requirements.txt`, в качестве интерпретатора нужно поставить интерпретатор с Python **3.7.1**;
